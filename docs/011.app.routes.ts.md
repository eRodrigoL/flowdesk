# app.routes.ts

`app.routes.ts` é um arquivo usado para concentrar a definição das rotas da aplicação. Sua função é reunir, em um ponto central, os caminhos que a aplicação reconhece e qual componente, redirecionamento ou configuração deve ser usado em cada caso. No Angular atual, é comum criar um arquivo `app.routes.ts` que exporta uma constante `routes` do tipo `Routes`.

No Angular 21, esse arquivo faz parte da organização moderna do roteamento em aplicações standalone. Em vez de declarar rotas em um módulo raiz, a aplicação costuma manter as rotas em `app.routes.ts` e registrá-las em `app.config.ts` com `provideRouter(routes)`.

Uma forma simples de entender essa organização é:

- `main.ts` [🔍](./010-main.ts.md) inicia a aplicação
- `app.config.ts` [🔍](./009-app.config.ts.md) registra a configuração global
- `app.routes.ts` concentra as rotas
- componentes cuidam da interface
- serviços cuidam da lógica e do acesso a dados

Essa separação ajuda a deixar cada arquivo com uma responsabilidade mais clara. No Angular Router, as rotas definem qual componente deve ser exibido para uma determinada URL, enquanto os outlets são os pontos do template onde esse conteúdo será renderizado.

---

## 1. Estrutura básica

A estrutura de `app.routes.ts` entregue pelo CLI é:

```ts
import { Routes } from '@angular/router';

export const routes: Routes = [];
```

Nesse exemplo:

- `Routes` é o tipo usado para tipar a lista de rotas
- `routes` é a constante exportada com a configuração
- cada item do array representa uma rota da aplicação

---

## 2. Exemplo com páginas

```ts
import { Routes } from '@angular/router';

import { Listagem } from '@pages/chamados/listagem/listagem';

export const routes: Routes = [
  // Com component
  { path: '', component: Listagem, pathMatch: 'full' },

  // Com loadComponent
  {
    path: 'chamados/novo',
    loadComponent: () => import('@pages/chamados/criacao/criacao').then((m) => m.Criacao),
  },

  // Passando id
  {
    path: 'chamados/:id/editar',
    loadComponent: () => import('@pages/chamados/edicao/edicao').then((m) => m.Edicao),
  },

  // Com redirectTo
  {
    path: '**',
    redirectTo: '',
  },
];
```

```ts
//         ┌── Routes ➡️ tipo fornecido pelo Angular Router para tipar a lista de rotas
import { Routes } from '@angular/router';
import { Listagem } from '@pages/chamados/listagem/listagem';
//         └── Listagem ➡️ componente usado diretamente na rota inicial

export const routes: Routes = [
  //            │       └── Routes ➡️ tipa o array de rotas
  //            └── routes ➡️ constante que concentra a configuração das rotas da aplicação

  // USANDO COMPONENT
  //  ┌── path: '' ➡️ rota raiz da aplicação
  //  │           ┌── component: Listagem ➡️ componente exibido quando a URL acessada é a raiz
  //  │           |                   ┌── pathMatch: 'full' ➡️ exige correspondência exatamente igual para ativar rota
  { path: '', component: Listagem, pathMatch: 'full' },

  // USANDO LOADCOMPONENT
  //  ┌── path: 'chamados/novo' ➡️ rota para criação de chamado
  {
    path: 'chamados/novo',
    loadComponent: () => import('@pages/chamados/criacao/criacao').then((m) => m.Criacao),
  },
  // │   │                                                          |           └── m.Criacao ➡️ componente retornado do módulo importado
  // |   |                                                          └── .then((m) => ➡️ ?
  // │   └── import(...) ➡️ importação dinâmica do arquivo do componente
  // └── loadComponent: () => ... ➡️ carrega o componente sob demanda

  // USANDO PARÂMETRO DINÂMICO
  //  ┌── path: 'chamados/:id/editar' ➡️ rota de edição com parâmetro dinâmico
  //  │              ┌── :id ➡️ parâmetro passado dinamicamente à rota
  {
    path: 'chamados/:id/editar',
    loadComponent: () => import('@pages/chamados/edicao/edicao').then((m) => m.Edicao),
  },

  // USANDO REDIRECTTO
  //  ┌── path: '**' ➡️ rota curinga para URLs não encontradas
  {
    path: '**',
    redirectTo: '',
  },
  //  └── redirectTo: '' ➡️ redireciona para a rota raiz
];
```
