# app.config.ts

`app.config.ts` é um arquivo de configuração da aplicação. Sua função é concentrar definições globais em um ponto central, facilitando organização, leitura e manutenção.

No Angular 21, esse arquivo faz parte da forma moderna de iniciar e configurar a aplicação. Em vez de centralizar tudo em um módulo raiz, a configuração principal costuma ficar distribuída entre o bootstrap da aplicação, o arquivo de configuração global e o arquivo de rotas. Providers como `provideRouter(...)` e `provideHttpClient()` são exemplos comuns desse uso.

Uma forma simples de entender essa organização é:

- `main.ts` [🔍](./010-main.ts.md) inicia a aplicação
- `app.config.ts` registra a configuração global
- `app.routes.ts` [🔍](./011.app.routes.ts.md) concentra as rotas
- componentes cuidam da interface
- serviços cuidam da lógica e do acesso a dados

Essa separação ajuda a deixar cada arquivo com uma responsabilidade mais clara. O `main.ts` usa `bootstrapApplication(...)` para iniciar a aplicação, e o `app.config.ts` é usado nesse processo para fornecer a configuração global da aplicação.

---

## 1. Estrutura básica

Uma estrutura básica de `app.config.ts` costuma ser esta:

```ts
import { ApplicationConfig } from '@angular/core';
import { provideRouter } from '@angular/router';

import { routes } from './app.routes';

export const appConfig: ApplicationConfig = {
  providers: [provideRouter(routes)],
};
```

Nesse exemplo:

- `ApplicationConfig` tipa o objeto de configuração
- `providers` reúne os providers globais da aplicação
- `provideRouter(routes)` registra o roteamento
- `routes` normalmente vem de `app.routes.ts`

---

## 2. Exemplo com roteamento e HTTP

Um exemplo comum é combinar roteamento e cliente HTTP no mesmo arquivo:

```ts
import { ApplicationConfig } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';
import { provideRouter } from '@angular/router';

import { routes } from './app.routes';

export const appConfig: ApplicationConfig = {
  providers: [provideRouter(routes), provideHttpClient()],
};
```

Nesse caso:

- `provideRouter(routes)` disponibiliza o roteamento da aplicação
- `provideHttpClient()` disponibiliza o `HttpClient` para injeção em serviços e outros pontos da aplicação
